# Quickstart

The fastest way to get Agevine running is using Docker Compose. This single command will spin up the entire platform (PostgreSQL, API Gateway, and Dashboard UI) on your local machine or server.

## 1. Clone the Repository

```bash
git clone https://github.com/yourusername/agevine-oss.git
cd agevine-oss/oss
```

## 2. Boot the Platform

```bash
docker-compose up -d
```

Docker will download the necessary Node.js and PostgreSQL images, build the Agevine microservices, and network them together.

## 3. Access the Dashboard

Once the containers are running, open your browser and navigate to:

**[http://localhost:3000](http://localhost:3000)**

You will be presented with a login screen. The default administrator password is:

```
agevine
```

*(You can change this password by modifying the `ADMIN_PASSWORD` variable in the `docker-compose.yml` file).*

## 4. Send Test Data

You can immediately test the platform by running the built-in simulator scripts from the root directory:

```bash
# Simulate an Apple Watch sending vitals
node packages/wearables/test-sdk.js

# Simulate an AI Voice Caller
node packages/voice/test-voice-sdk.js
```

Refresh your dashboard to see the data appear in real-time!
