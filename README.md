# Agevine OSS (Open Source Core)

This directory contains the foundational, open-source building blocks of the Agevine elder care platform. It is designed so that any developer can self-host the basic infrastructure for their own family.

## Components

- **`api-gateway/`**: The core API for managing patients, users, and basic health readings.
- **`ui-core/`**: A UI component library and a basic version of the Family Dashboard.
- **`voice-engine/`**: The foundational code for placing and receiving calls, handling webhooks, and basic speech-to-text transcriptions.
- **`wearable-sdk/`**: Standard libraries for ingesting raw data from standard wearable APIs (Apple HealthKit, Google Fit).
- **`landing-page/`**: The light-theme, open-source landing page design.
